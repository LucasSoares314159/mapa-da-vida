# **REGRAS DE PONTUAÇÃO DO QUIZ**

## **1\. Objetivo**

Identificar qual das três dificuldades é mais representativa das respostas do participante e exibir o resultado correspondente.

**Perfis:**

* **A — Objetivos em conflito:** dificuldade para definir prioridades coerentes.  
* **B — Planos sem sustentação:** dificuldade para transformar objetivos em ações e manter a execução.  
* **C — Uma rotina sem espaço:** sobrecarga de compromissos, tempo e energia.

Existe também o **Resultado Alternativo — Análise Geral**, utilizado quando não há evidências suficientes de uma dificuldade predominante.

Essas classificações são interpretações das respostas, não diagnósticos psicológicos.

## **2\. Regras gerais de pontuação**

Cada participante começa com:

* Pontuação A \= 0  
* Pontuação B \= 0  
* Pontuação C \= 0

Cada resposta pode adicionar pontos a uma ou mais dimensões.

As perguntas que investigam diretamente as causas do problema recebem maior peso. Perguntas sobre desejos pessoais não devem, por si só, determinar um diagnóstico.

## **4\. Regra de classificação**

Após a sexta resposta:

**Passo 1:** somar os pontos de cada dimensão.

**Passo 2:** identificar a maior pontuação.

**Passo 3:** aplicar as seguintes regras:

* Se a maior pontuação for **zero**, exibir Análise Geral.  
* Se houver uma dimensão com pontuação maior ou igual a **4 pontos** e vantagem de pelo menos **2 pontos** sobre a segunda colocada, atribuir essa dimensão.  
* Se a vantagem for inferior a 2 pontos, aplicar os critérios de desempate.  
* Se nenhuma dimensão alcançar 4 pontos, exibir Análise Geral.

### **Critérios de desempate**

**Primeiro:** verificar a Pergunta 4, que investiga a coerência dos objetivos.

Se a resposta da Pergunta 4 favorecer uma das dimensões empatadas, atribuir essa dimensão.

**Segundo:** se o empate permanecer, verificar a Pergunta 6, que investiga a principal mudança desejada.

Se ela favorecer apenas uma das dimensões empatadas, atribuir essa dimensão.

**Terceiro:** se o empate persistir, exibir Análise Geral.

Os critérios de desempate não se aplicam quando a maior pontuação é inferior a 4\.

## **7\. Dados que devem ser registrados**

Para cada conclusão do quiz, armazenar:

* Identificador da sessão ou participante.  
* Respostas Q1 a Q6.  
* Pontuação final A, B e C.  
* Perfil atribuído.  
* Regra utilizada para a atribuição.  
* Data e horário da conclusão.  
* Parâmetros de origem do tráfego, quando disponíveis.

Esses dados permitirão avaliar quais perfis chegam à Mini-VSL, clicam no checkout e compram.

## **8\. Direcionamento após o resultado**

Todos os perfis devem seguir para a mesma Mini-VSL.

O resultado serve para personalizar a interpretação das respostas, não para criar ofertas diferentes.

**Fluxo:**

Quiz → Cálculo → Resultado personalizado → Botão “ASSISTIR À MINHA ANÁLISE” → Mini-VSL → Checkout.

## **9\. Observações para implementação**

* Não alterar a redação das perguntas ou dos resultados sem aprovação.  
* Não utilizar a Pergunta 2 como critério de pontuação.  
* Não atribuir resultados aleatoriamente.  
* Não exibir um resultado predominante quando os critérios de pontuação não forem satisfeitos.  
* Garantir que o cálculo seja reproduzível: as mesmas respostas devem gerar o mesmo resultado.  
* Testar todos os cenários antes da publicação.

**Status:** proposta de lógica de classificação para validação. Os pesos e limiares são hipóteses operacionais e devem ser avaliados com respostas reais antes de serem tratados como um diagnóstico validado.
